# 🌐 Personal Portfolio Website

A personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my work, introduce myself, and provide a foundation for my online presence.

🔗 **Live Website:** [View Portfolio](https://wm-111.github.io/portfolio/)

---

## 📌 About the Project

This repository contains the source code for my personal portfolio website. It is built using core front-end technologies, with separate files for the website structure, styling, and JavaScript functionality.

The project is designed to be lightweight, easy to maintain, and simple to customize.

## ✨ Features

* 🌍 Personal portfolio website
* 🎨 Custom styling with CSS
* ⚡ JavaScript functionality and interactivity
* 📱 Viewport configuration for responsive browser rendering
* 🚀 Deployment using GitHub Pages
